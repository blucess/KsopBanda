📖 Cara Mudah Mendapatkan Web App URL (Hanya 2 Menit):
  1. Buka script.google.com dengan akun Google kantor Anda, lalu klik + New Project.
  2. Hapus semua kode bawaan, lalu Paste (Tempel) kode skrip yang sudah Anda salin di atas.
  3. Klik tombol biru Deploy > New deployment di kanan atas:
    • Pilih jenis: Web app (ikon gerigi).
    • Execute as: Me (akun Google Anda).
    • Who has access: Anyone (Siapa saja — agar aplikasi bisa kirim arsip).
  4. Klik Deploy, berikan izin akses Google (Authorize), lalu salin Web app URL dan tempelkan ke kolom input di atas.
